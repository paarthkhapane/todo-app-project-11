# Standalone UI/UX Prototype

This prototype is a design demonstration for the GRP 11 To-Do application.

## Preview

Open [index.html](./index.html) directly in a browser, or serve the repository with:

```powershell
cd C:\Users\ADMIN\Desktop\clg\todo-app-project-11
python -m http.server 8000
```

Then visit `http://localhost:8000/docs/ui-ux/prototypes/index.html`.

## Demonstrated interactions

- Login and Registration layouts
- Show/hide password
- User/Admin role demo entry
- User task filters
- Task completion
- Add and edit task modal
- Delete confirmation modal
- User search and role filter
- Admin task search and status filter
- Responsive statistics and chart layouts

All visible content is clearly identified as illustrative demo content. The prototype has no real authentication, API, database, or backend authorization.
